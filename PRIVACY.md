# Конфіденційність Небо.UA

Небо.UA не вимагає реєстрації, не використовує аналітику та не збирає ім’я, email, телефон чи історію переміщень.

Обрана область, налаштування звуку та технічний зріз для недопущення повторного сигналу зберігаються тільки у `localStorage` вашого пристрою. Геолокація запитується лише після натискання відповідної кнопки, використовується локально для визначення області та не надсилається на сервер Небо.UA. Історія геолокації не створюється.

Запити до джерел даних і картографічних тайлів можуть передавати стандартні технічні дані на кшталт IP-адреси відповідним постачальникам. Реклама зараз вимкнена, рекламні мережі та ідентифікатори не підключені.

Пошук населеного пункту виконується лише після натискання «Знайти» через OpenStreetMap Nominatim. Пошуковий запит та стандартні технічні дані з’єднання надсилаються цьому сервісу. Після явного дозволу браузера координати використовуються один раз для визначення найближчої адміністративної одиниці; точні координати не записуються у профіль і не надсилаються на сервер Небо.UA.

Налаштування сповіщень зберігаються локально. Фонові push-сповіщення — лише за явною згодою: увімкнення в налаштуваннях створює push-підписку браузера, яка разом з обраними місцями, категоріями та тихими годинами зберігається на сервері агрегатора без акаунта (ідентифікатор — сам endpoint підписки). Видалення підписки (вимкнення тумблера) стирає запис із сервера. Старі події новим підпискам не надсилаються. Реклама та продаж даних про місцезнаходження відсутні.
