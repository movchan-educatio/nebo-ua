# Архітектура

Статичний mobile-first PWA без backend і секретів. `services/` ізолює API та підготовлений для повторного використання майбутнім Telegram-ботом. UI, карта та service worker не кешують live API-відповіді. Помилки потоків тривог і загроз незалежні.

GitHub Pages підтримується відносними шляхами. У майбутньому FREE/PRO можна додати окремим feature layer; базова інформація про небезпеку не повинна потрапляти за paywall.
